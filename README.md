# NAVER Minimal - Microsoft Edge 확장 프로그램

네이버 메인 주소(`https://www.naver.com/` 또는 `https://naver.com/`)로 이동하면 복잡한 화면 대신 집중할 수 있는 깔끔한 미니멀 검색 페이지로 자동 전환합니다.

---

## 🌟 주요 기능

1. **미니멀 네이버 검색**
   - 불필요한 배너, 뉴스 피드, 광고 없이 검색창에만 집중할 수 있는 다크 모드 인터페이스
   - 검색어 입력 후 Enter 시 기존 네이버 통합검색 결과로 즉시 연결
   - 검색어 지우기 버튼(X) 제공

2. **오늘의 날씨 위젯**
   - 현재 위치(또는 기본 서울)의 실시간 날씨 상태(맑음, 구름, 비 등) 및 기온 표시
   - 날씨 클릭 시 네이버 날씨 상세 페이지로 바로 이동
   - 불필요한 트래픽을 방지하기 위한 로컬 캐시(25분) 적용

3. **네이버 주요 서비스 바로가기 (Quick Links)**
   - 검색창 아래 깔끔한 아이콘으로 자주 쓰는 네이버 핵심 서비스에 원클릭 접속
   - 지원 서비스: **메일**, **카페**, **블로그**, **MYBOX**, **쇼핑**, **뉴스**, **지도**, **웹툰**
   - 호버 시 부드러운 애니메이션 및 네이버 시그니처 그린 액센트

4. **실시간 시계 및 날짜**
   - 한국어 요일 및 날짜 표기

---

## 🚀 설치 방법 (Edge / Chrome)

1. 저장소를 클론하거나 ZIP 압축을 풉니다.
2. Edge 주소창에 `edge://extensions` 입력 (Chrome의 경우 `chrome://extensions`)
3. 오른쪽 상단 또는 왼쪽 하단의 **개발자 모드**를 켭니다.
4. **압축 풀린 확장 로드** 버튼을 클릭합니다.
5. `naver-minimal-edge-extension` 폴더를 선택합니다.
6. `https://www.naver.com/`에 접속해 변경된 미니멀 화면을 확인합니다.

---

## 💡 사용 안내 & 동작 방식

- **네이버 메인 페이지**: 미니멀 페이지(`minimal.html`)로 자동 전환
- **네이버 검색 결과 및 하위 서비스**: 기존 네이버 페이지(`search.naver.com`, `mail.naver.com` 등) 그대로 유지
- **권한**: Manifest V3 정적 리다이렉트(`declarativeNetRequest`) 규칙 및 날씨 API 조회를 위한 최소한의 도메인 권한만 사용
- 확장 프로그램을 비활성화하거나 삭제하면 원래의 네이버 홈으로 즉시 복구됩니다.
